# ArchiveBot ROS 2

Autonomous Warehouse Inspection Robot

ArchiveBot is an autonomous mobile robot developed using ROS 2 and Gazebo Sim.

## Features

- Autonomous warehouse navigation
- LiDAR-based obstacle detection
- Camera-based RED and GREEN checkpoint inspection
- Automatic return to the starting position
- Automatic parking orientation
- CSV inspection reports
- ROS 2 and Gazebo integration

## Project Structure

- models/ : Robot URDF/Xacro models
- worlds/ : Gazebo warehouse environment
- scripts/ : Navigation and vision algorithms
- config/ : ROS 2 - Gazebo bridge configuration
- launch/ : Launch configurations
- rviz/ : Visualization configurations

## Current Version

- Complete inspection route

- Return navigation
